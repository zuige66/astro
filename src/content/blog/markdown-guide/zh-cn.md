# Markdown 语法入门指南

## 一、标题 (Heading)

使用 `#` 符号创建标题，`#` 的数量决定标题级别：

```markdown
# 一级标题 (H1)
## 二级标题 (H2)
### 三级标题 (H3)
#### 四级标题 (H4)
##### 五级标题 (H5)
###### 六级标题 (H6)
```

**效果：**
# 一级标题
## 二级标题  
### 三级标题

---

## 二、文本样式

### 粗体 (Bold)

使用 `**文本**` 或 `__文本__`：

```markdown
**这是粗体文本**
__这也是粗体文本__
```

**效果：** **这是粗体文本**

### 斜体 (Italic)

使用 `*文本*` 或 `_文本_`：

```markdown
*这是斜体文本*
_这也是斜体文本_
```

**效果：** *这是斜体文本*

### 粗斜体 (Bold + Italic)

组合使用：

```markdown
***粗斜体文本***
___粗斜体文本___
```

**效果：** ***粗斜体文本***

### 删除线 (Strikethrough)

使用 `~~文本~~`：

```markdown
~~这是被删除的文本~~
```

**效果：** ~~这是被删除的文本~~

---

## 三、列表 (List)

### 无序列表 (Unordered List)

使用 `-`、`*` 或 `+`：

```markdown
- 列表项1
- 列表项2
- 列表项3
  - 嵌套项3.1
  - 嵌套项3.2
```

**效果：**
- 列表项1
- 列表项2
- 列表项3
  - 嵌套项3.1
  - 嵌套项3.2

### 有序列表 (Ordered List)

使用 `数字.`：

```markdown
1. 第一项
2. 第二项
3. 第三项
   1. 子项3.1
   2. 子项3.2
```

**效果：**
1. 第一项
2. 第二项
3. 第三项
   1. 子项3.1
   2. 子项3.2

### 任务列表 (Task List)

使用 `- [ ]` 和 `- [x]`：

```markdown
- [ ] 未完成任务
- [x] 已完成任务
- [ ] 待办事项
```

**效果：**
- [ ] 未完成任务
- [x] 已完成任务
- [ ] 待办事项

---

## 四、链接 (Link)

### 基础链接

```markdown
[链接文本](URL地址)
[百度](https://www.baidu.com)
```

**效果：** [百度](https://www.baidu.com)

### 带标题的链接

```markdown
[链接文本](URL地址 "鼠标悬停提示")
[Google](https://www.google.com "访问Google")
```

**效果：** [Google](https://www.google.com "访问Google")

### 引用式链接

```markdown
[链接文本][引用标签]

[引用标签]: URL地址 "可选标题"

示例：
[GitHub][1]

[1]: https://github.com "GitHub官网"
```

---

## 五、图片 (Image)

```markdown
![替代文本](图片URL)
![示例图片](https://picsum.photos/200/100)
```

**效果：**
![示例图片](https://picsum.photos/200/100)

带标题的图片：
```markdown
![替代文本](图片URL "图片标题")
```

---

## 六、代码 (Code)

### 行内代码 (Inline Code)

使用反引号 `` ` ``：

```markdown
使用 `console.log()` 输出信息
```

**效果：** 使用 `console.log()` 输出信息

### 代码块 (Code Block)

使用三个反引号 ```，可指定语言高亮：

```markdown
```javascript
function hello() {
  console.log("Hello World!");
}
```
```

**效果：**
```javascript
function hello() {
  console.log("Hello World!");
}
```

---

## 七、表格 (Table)

使用 `|` 分隔列，`-` 分隔表头和内容：

```markdown
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25 | 北京 |
| 李四 | 30 | 上海 |
| 王五 | 28 | 广州 |
```

**效果：**
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25 | 北京 |
| 李四 | 30 | 上海 |
| 王五 | 28 | 广州 |

### 对齐方式

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:------|:-------:|------:|
| 内容 | 内容 | 内容 |
```

**效果：**
| 左对齐 | 居中对齐 | 右对齐 |
|:------|:-------:|------:|
| 内容 | 内容 | 内容 |

---

## 八、引用 (Blockquote)

使用 `>` 符号：

```markdown
> 这是一段引用文本
> 
> 引用可以有多行
> > 嵌套引用
```

**效果：**
> 这是一段引用文本
> 
> 引用可以有多行
> > 嵌套引用

---

## 九、水平线 (Horizontal Rule)

使用 `---`、`***` 或 `___`：

```markdown
---
***
___
```

**效果：**
---

---

## 十、脚注 (Footnote)

```markdown
这是带脚注的文本[^1]

[^1]: 这是脚注的内容
```

**效果：**
这是带脚注的文本[^1]

[^1]: 这是脚注的内容

---

## 十一、表情符号 (Emoji)

直接输入表情符号或使用代码：

```markdown
:smile: :heart: :star: :rocket:
```

**效果：** 😊 ❤️ ⭐ 🚀

## 常用快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+B | 粗体 |
| Ctrl+I | 斜体 |
| Ctrl+K | 插入链接 |
| Ctrl+Shift+C | 插入代码块 |
| Ctrl+L | 插入链接 |

---

## 编写建议

1. **保持简洁**：使用合适的标题层级，避免过度嵌套
2. **使用列表**：长文本使用列表提高可读性
3. **代码格式化**：代码片段使用代码块包裹
4. **表格对齐**：使用对齐符号使表格更美观
5. **预览检查**：写完后预览确保格式正确

---

> **提示**：不同的 Markdown 渲染器对语法的支持可能略有差异，以上是标准的 CommonMark 语法。

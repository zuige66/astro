最近开始管理自己的服务器，最先接触的是 Tabby，后来又开始使用 MobaXterm。两者都能通过 SSH 连接 Linux 服务器，也都能保存连接信息、使用密钥、传文件；但实际用下来，手感并不一样。

我现在更常用 MobaXterm。它的界面不如 Tabby 简洁好看，但在 SSH 里输入和执行命令时，我这边感觉更跟手、更稳定。Tabby 的图形化界面和标签页设计我很喜欢，不过连接服务器后输入命令偶尔有一点卡顿，不太舒服。这篇只记录两款 SSH 工具的区别和最基础用法，不讨论服务器部署方案。

文中用 `YOUR_SERVER_IP` 代替服务器地址，用 `root` 作为示例用户名。实际连接时要换成自己的公网 IP、端口和用户名；不要把密码、私钥或真实服务器信息发到公开文章和截图里。

## 先说结论

如果主要在 Windows 上管理服务器，希望 SSH 终端输入顺畅、连接后能直接看到服务器文件，并且偶尔会用到远程桌面、X11 或其他远程协议，我更推荐先试 **MobaXterm**。

如果在意界面美观、希望在 Windows、macOS 和 Linux 上使用同一款终端，或者偏好标签页、分屏和可定制的终端体验，**Tabby** 更值得尝试。

它们没有谁绝对更好。SSH 最重要的是“自己输入命令时是否舒服、连接是否稳定”。我现在把 MobaXterm 当作主力连接工具，Tabby 留作界面更轻松、需要多标签浏览时的选择。

## 两个工具分别是什么

### Tabby：更像现代终端

Tabby 是跨平台终端工具，支持 Windows、macOS 和 Linux。它本身可以管理 SSH 连接，也支持标签页、分屏、SFTP、跳板机和端口转发等功能。[Tabby 官方功能页](https://tabby.sh/about/features)

它给我的第一感觉是界面清爽：配置、主题、标签页和分屏都做得比较现代。如果平时除了 SSH，还经常在本机开 PowerShell、Git Bash 或 WSL，Tabby 可以把这些终端放在同一个界面里管理。

### MobaXterm：更像 Windows 上的远程工具箱

MobaXterm 更偏向 Windows 的“一体化远程连接工具”。除 SSH 外，它还集成了 SFTP 文件浏览、RDP、VNC、FTP、X11 等功能。[MobaXterm 官方文档](https://mobaxterm.mobatek.net/documentation.html)

我喜欢它的一点是：通过 SSH 成功登录后，通常可以在左侧直接看到服务器文件目录，不必再额外开一个传输软件。对于刚接触服务器的人来说，这种“终端和文件都在一页”的形式很直观。

## 详细对比

| 项目 | Tabby | MobaXterm |
| --- | --- | --- |
| 平台 | Windows、macOS、Linux | 以 Windows 为主 |
| 界面风格 | 简洁、现代，主题和终端体验更突出 | 功能密集，更像传统远程管理工具 |
| SSH 输入体验 | 我的环境里偶尔感觉有轻微卡顿 | 我的环境里输入和回显更跟手 |
| 保存连接 | 可以保存 SSH 配置，方便复用 | 可以保存 Session，适合管理多台机器 |
| 文件传输 | 支持 SFTP | SSH 连接后常可直接使用左侧 SFTP 文件树 |
| 分屏与标签页 | 标签页、分屏是强项 | 也支持多会话和标签页，重点偏远程管理 |
| 其他协议 | 重点是终端与 SSH 工作流 | 集成 RDP、VNC、FTP、X11 等更多工具 |
| 更适合谁 | 喜欢现代终端、跨平台使用的人 | Windows 上管理服务器、希望一站式操作的人 |

### 界面与使用感

Tabby 的配置页面、图标、主题和标签栏都很舒服，适合长时间打开很多终端窗口。它的分屏也方便，例如左边查看日志、右边执行命令，或者同时连两台服务器。

MobaXterm 的界面信息更多，刚开始可能显得有点复杂；但它把常用的远程操作摆得很直接。尤其是 SSH 登录成功后左侧的 SFTP 文件树，上传、下载、拖拽文件会比较省事。

### 命令输入为什么可能感觉卡

SSH 命令输入的卡顿不一定是 Tabby 本身的问题，也可能来自网络延迟、服务器负载、终端渲染、字体或插件。因为我在 MobaXterm 中感觉更顺，所以目前选择它做主要工具；这只是我的实际体验，不代表 Tabby 在所有电脑和服务器上都会慢。

如果想判断问题在哪，可以用同一台服务器、同一个网络、同一个账号分别测试两款工具：连续输入几行短命令，观察字符是否立即回显；再运行 `ping`、`top` 之类的命令看网络和服务器是否本身有延迟。若只有 Tabby 卡，优先检查它的主题、字体、插件或关闭后重新打开测试；若两边都卡，更可能是网络或服务器状态造成的。

## MobaXterm 的基础用法

下面是我现在更常用的连接方式。

### 新建 SSH 会话

1. 打开 MobaXterm，点击左上角的 **Session**。
2. 选择 **SSH**。
3. 在 **Remote host** 填写服务器公网 IP，例如 `YOUR_SERVER_IP`。
4. 勾选 **Specify username**，填写服务器用户名，例如 `root`。
5. SSH 端口默认是 `22`；如果服务器改过端口，在 Port 中填实际数字。
6. 点击 **OK** 连接。第一次连接会要求确认服务器主机指纹，确认目标确实是自己的服务器后再接受。

首次使用密码登录时，终端会要求输入服务器密码。输入时屏幕通常不会显示星号或字符，这是正常的，输完直接按 Enter 即可。

连接成功后，MobaXterm 会把这台机器保存到左侧的 Sessions 列表。之后双击该会话就能重新连接，不必每次再填 IP 和用户名。

### 用左侧 SFTP 面板传文件

SSH 登录成功后，MobaXterm 通常会在左侧显示服务器文件目录。这是基于 SFTP 的文件浏览器。

- 从本地向服务器上传：把文件拖进左侧对应目录，或使用上传按钮。
- 从服务器下载：选中服务器文件，再选择下载到本地的位置。
- 新建、重命名或删除文件：先确认当前路径和目标文件，再用右键菜单操作。

命令行和 SFTP 面板看到的是同一台服务器、同一个登录用户的文件。比如终端显示在 `/root`，左侧文件树通常也是这个用户有权限访问的位置。涉及删除或覆盖时，我会先在终端用 `pwd` 和 `ls -la` 确认目录，再操作文件面板。

### 常用的几个界面操作

- **多开会话**：再次双击左侧保存的服务器，会在新的标签页连接。
- **断开连接**：关闭对应标签页即可；不会关掉服务器上的程序。
- **复制文本**：服务器命令和报错优先复制为文本，不要只截屏，后续排查更方便。
- **保存密码**：可以保存，但更建议之后配置 SSH 密钥登录，避免把密码长期交给客户端保存。

## Tabby 的基础用法

Tabby 的 SSH 配置思路和 MobaXterm 一样，只是界面组织不同。

1. 打开 Tabby 的设置或连接管理区域，新建一个 **SSH profile**。
2. 填写主机地址 `YOUR_SERVER_IP`、端口 `22` 和登录用户名。
3. 首次可以按服务器当前的认证方式输入密码；之后可在配置中选择私钥登录。
4. 保存配置，回到主界面打开这个 profile，建立 SSH 会话。

Tabby 比较适合把常用连接整理成 profile。例如可以按“新加坡服务器”“测试服务器”“本机 WSL”来命名，避免只靠 IP 区分。它也可以在同一个窗口内开多个标签页或分屏；但如果你的使用感受和我一样，SSH 输入时不够舒服，就没有必要勉强把它当主力工具。

## 两者都能使用 SSH 密钥

无论使用 Tabby 还是 MobaXterm，SSH 密钥的原理都一样：私钥留在本机，公钥放在服务器用户的 `~/.ssh/authorized_keys`。客户端里需要选择的是本机的**私钥**，不能把私钥上传到服务器，也不要把它发给任何人。

配置方法细节可以单独展开写；对当前选择工具来说，只要记住一件事：换 SSH 客户端不需要重新生成一套密钥。只要用户名、服务器地址和同一把私钥都正确，两款工具都可以连接同一台服务器。

## 我现在的选择

我目前会继续用 MobaXterm 连接服务器，因为命令输入的手感对我更重要，左侧 SFTP 文件面板也很方便。Tabby 的图形化界面、标签页和整体视觉体验确实更好，之后如果它在我的环境里输入更稳定，或者我需要跨平台管理终端，我还会再用它。

工具的选择不用一次定死。先用最顺手、能稳定完成连接和文件管理的工具，再慢慢形成自己的工作流就够了。
